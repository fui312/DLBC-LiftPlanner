# DLBC-LiftPlanner
Mobile crane lift planner for DLB Cranes.

Home page is `index.html`: library sidebar (Crane List, Lift Studies, Rigging) and recently opened files. Settings stores units, theme, and Advanced Mode in this browser. Units default from the browser region (US, LR, MM imperial; otherwise metric). Theme defaults to dark. Brand colours are `#FF0000` and `#0000FF` on a dark UI.
